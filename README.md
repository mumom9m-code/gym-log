# دفتر التمرين — طريقة النشر على GitHub Pages

## الملفات
- `index.html` — التطبيق كامل (الخطوط مدمجة فيه)
- `manifest.webmanifest` و `sw.js` — للتثبيت والعمل بدون نت
- `icons/` — أيقونات التطبيق (4 ملفات)
- `ex/` — صور الحركات المتحركة (97 ملف)

## الرفع (مرتين لأن GitHub يقبل 100 ملف كحد أقصى في الرفعة الواحدة)
1. افتح المستودع على GitHub ← **Add file** ← **Upload files**.
2. **الرفعة الأولى:** اسحب مجلد `ex` كامل وأفلته، ثم **Commit changes**.
3. **الرفعة الثانية:** اسحب الباقي (`index.html` و`manifest.webmanifest` و`sw.js` و`README.md` ومجلد `icons`) ثم **Commit changes**.
4. لو المستودع جديد: **Settings ← Pages ← Branch: main ← / (root) ← Save**.
5. افتح الرابط من الجوال، ومن قائمة المتصفح اختر **إضافة إلى الشاشة الرئيسية** / **تثبيت التطبيق**.

## ملاحظات
- لو رفعته مكان النسخة القديمة بنفس الرابط: بياناتك القديمة ما تنمسح — تنحفظ جانباً وتدخل في النسخة الاحتياطية.
- بعد أول فتح، من **الإعدادات ← نزّل كل الحركات** عشان الصور تشتغل بدون نت.
- لا تفتح `index.html` من الجوال كملف مباشرة — افتحه من الرابط عشان تنحفظ بياناتك.

صور الحركات من مكتبة [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (ملكية عامة)، معالجة بلون موحّد.
